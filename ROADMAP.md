# NEIMAN Roadmap

This roadmap prioritizes safe, incremental delivery. Readiness claims should be backed by reproducible checks and operational evidence.

## Current priorities

1. **Security and tenant isolation:** verify authorization on every domain endpoint; keep tool execution behind enforceable capability boundaries; improve URL egress policy and secret handling.
2. **Durable operations:** PostgreSQL migration coverage, background workers, retries/idempotency, and readiness probes.
3. **Organizational performance:** outcome metrics for agents, teams, workflows, and provider routes.
4. **Validated evolution:** immutable configuration versions, simulation, human approval, deployment monitoring, and rollback.
5. **Integration quality:** generated/shared API types, end-to-end workflow coverage, and operational runbooks.
6. **Frontend quality:** complete keyboard/mobile review for all organization workflows, add browser-level visual coverage, and consolidate the duplicate intelligence experiences.

## Later opportunities

- WebSocket event hub standardization.
- Semantic memory backed by a production vector index.
- Provider health telemetry and routing based on measured capability, latency, cost, and policy.
- Simulation lab and conversational organization setup, gated by validated configuration and human approval.
